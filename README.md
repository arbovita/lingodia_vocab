# lingodia_vocab

Lingo Día Daily Vocab Trainer

Files:
- index.html
- style.css
- script.js
- vocab.js

What this version does:
- Spanish 2 focused
- Lessons 1–6
- Category selector
- Daily quiz set selector
- Learn, Recall, Type, Match, Final Check, Missed Words, Word Bank
- Uses localStorage for progress
- No backend, no login, no paid service

Important note:
The daily set labels and term counts are based on the quiz set list the student pasted.
The exact membership of each Quizlet set was not provided, so the site distributes
lesson vocabulary into those daily set labels as a best-effort starting point.
To make it exact, edit vocab.js and change each word's dailySet field.
